## Этап 0.

**Источник:** [OddsPapi](https://oddspapi.io), REST API `https://api.oddspapi.io/v4`. Отдаёт текущие и исторические коэффициенты сотен букмекеров. Для истории изменений коэффициентов есть отдельный метод `/historical-odds`.

**Что выгрузили:**
- 16 матчей Английской Премьер-лиги, туры 12–13 и 19–20 сентября 2026 (окно 11–20 сентября). Изначально брали окно 25 сентября – 4 октября, но не подошло: там пауза на матчи сборных, матчей АПЛ нет.
- Букмекеры: Pinnacle, Singbet, SBOBET (на них ориентируется рынок) и bet365 (крупный британский). William Hill тоже был в запросе, но API вернул по нему пустые данные.
- Рынки: 1X2 (исход матча, код `101`) и тотал больше/меньше 2.5 (код `1010`).
- Вся история изменений: от открытия линии (за 2 недели до матча) до конца матча, включая лайв.

**Как сделать свою выгрузку:**
1. Зарегистрироваться на oddspapi.io и получить API-ключ.
2. Скопировать `.env.example` в `.env` и вписать ключ: `ODDSPAPI_KEY=...`.
3. В ноутбуке `get_dataset.ipynb` в шаге 2 поменять даты, букмекеров или рынки и выполнить ячейки по порядку.

**Результат этапа — `data/raw/epl_odds_raw.csv`.** Ответ API развёрнут в таблицу: одна строка — одна запись истории. Значения не меняются. Добавлены только три поля матча из `/fixtures`, потому что в `/historical-odds` есть лишь ID матча.

## Этап 1. Предобработка

1. Удаляем служебные столбцы `playerId` и `exchangeMeta`: в наших данных в них ничего нет.
2. Переименовываем поля по смыслу (`createdAt` → `timestamp`, `active` → `bool_isActive`, `limit` → `pinnacle_limit` и т. д.).
3. Переводим время в datetime (UTC).
4. Проверяем дубликаты: их нет.
5. Удаляем 601 строку с ценой 1.0. Все они у bet365, все во время матча, почти все с закрытым рынком
6. Расшифровываем коды рынков и исходов.
7. Добавляем поля `match`, `hours_to_kickoff`, `stage`, `implied_prob`, `price_changed`.
8. Округляем, сортируем, сохраняем.

## немного о данных

- **Все время — UTC** (московское = UTC + 3).
- **Строка — это событие, а не снимок рынка.** API присылает запись, когда меняется цена или рынок закрывают и открывают
- **Почти половина строк — лайв.** Для анализа предматчевой линии фильтруйте `stage == "prematch"`.
- **SBOBET открывает линию поздно,** за 0,5–6 дней до матча. На дальних горизонтах есть только три букмекера.
- **По матчу Chelsea — Hull City** у Singbet и SBOBET нет тотала.
