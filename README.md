# Система обнаружения аномальных движений линии между букмекерами

Годовой проект 2026/27, трек **ML / Data Science**. Проект № 199.

Букмекеры устанавливают коэффициенты независимо друг от друга, а линия постоянно меняется под влиянием новостей, травм и ставок игроков. Резкое движение сразу у нескольких букмекеров может говорить о появлении значимой информации. Изменение у одного оператора может быть связано с крупной ставкой или особенностями его работы. Мы хотим научиться замечать такие ситуации и отличать их от обычного рыночного шума.

Для этого разрабатываем систему, которая собирает коэффициенты из открытых источников, сопоставляет котировки на одно событие и обнаруживает резкие скачки и расхождения между букмекерами. По характеру движения и совпадениям с новостями она будет оценивать вероятную причину: рыночный шум, новостной фон или локальный фактор у отдельного оператора. Это именно оценка: по одним коэффициентам нельзя достоверно установить причину или объём ставок.

Итоговый продукт — дашборд или Telegram-алерты для трейдера с объяснением движения и оценкой того, требует ли оно внимания. Дополнительно планируем проверить на исторических данных, помогают ли обнаруженные сигналы предсказывать дальнейшее движение линии.
